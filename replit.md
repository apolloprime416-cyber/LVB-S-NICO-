# LVB Sônico — Painel de Keys

## Overview
License-key management system for the "LVB Sônico" browser extension.
- **Panel** (`artifacts/painel`, react-vite, served at `/`): admin dashboard + client area + public `/resetar-key` page. Dark theme: near-black background, white text, blue accents. All UI text pt-BR. No emojis (lucide-react icons only). Logo at `public/brand/logo.png`.
- **API** (`artifacts/api-server`, Express 5 at `/api`): session auth (express-session + connect-pg-simple, table `user_sessions`), bcryptjs passwords, license key lifecycle.
- **DB**: Replit PostgreSQL via Drizzle (`lib/db/src/schema/`): `users`, `license_keys`.
- **Extension source** (uploaded): `attached_assets/extension_src/SORAX/` — being rebranded to LVB Sônico with a key gate calling `/api/public/validate`.

## Key business rules
- Registration → status `pending` → admin approves/rejects.
- Admin login is 2-step: email+senha, then a numeric code (seeded admin account; credentials configurable via ADMIN_EMAIL / ADMIN_PASSWORD / ADMIN_2FA_CODE env, with defaults specified by the owner).
- Plans: trial (15 min, free), daily R$3,90, weekly R$8,90, monthly R$15,90, lifetime R$22,90 (never expires).
- **Keys only start counting time at activation** (panel activate or first extension validate, whichever comes first).
- Trial keys can only be generated by clients who own at least one paid key.
- Keys bind to one device fingerprint; reset via client panel, admin, or public `/resetar-key`.
- Public endpoints for the extension: `POST /api/public/validate` (activates on first use, binds device), `POST /api/public/reset-key`.

## Conventions / gotchas
- OpenAPI contract in `lib/api-spec/openapi.yaml`; codegen requires re-pointing the generated api-zod import to `zod/v4` (see `.agents/memory/orval-zod-v4.md`).
- `user_sessions` table must exist manually (see `.agents/memory/session-store.md`) — remember for production deploys.
- Admin seeding happens on api-server startup (`src/lib/seedAdmin.ts`).
